Ключ подписи Lane для Android. Все APK подписываются им, поэтому обновления
ставятся поверх. Не удаляйте и не меняйте: с другим ключом Android откажется
обновлять приложение (придётся удалить и поставить заново, потеряв данные).

Репозиторий приватный. Чтобы убрать ключ из кода, добавьте секреты Actions
LANE_KEYSTORE_B64 (base64 файла) и LANE_KEYSTORE_PASSWORD — workflow возьмёт их.
